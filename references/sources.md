# Trusted Source Patterns

## Source Hierarchy

1. **Official Documentation** - Primary authoritative source
2. **Engineering Blog Posts** - Detailed implementation insights
3. **Academic Papers** - Theoretical foundations
4. **Community Discussions** - Practical use cases and issues
5. **GitHub Repositories** - Source code and examples

## Search Patterns by Source Type

### Official Documentation
- Query: `"site:docs.example.com [topic]"`
- Query: `"[product] official documentation [feature]"`

### Engineering Blog Posts
- Query: `"[company] engineering blog [topic]"`
- Query: `"how [company] built [feature]"`

### Academic Papers
- Query: `"[topic] arxiv paper"`
- Query: `"[topic] research paper PDF"`

### GitHub
- Query: `"[topic] github repository"`
- Query: `"[topic] implementation github"`
